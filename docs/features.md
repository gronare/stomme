# Features

Optional collections, listings and the docs section each have their own page.

- [Turn on a feature](how-to/turn-on-a-feature.md): the blog, services, areas, testimonials, FAQ and documents, and events from the blog.

- [Build docs from a repo](how-to/build-docs-from-a-repo.md): a documentation section read from a folder of Markdown on GitHub.
